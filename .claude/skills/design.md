# Design

Comprehensive design toolkit that covers brand identity, UI systems, logo creation, corporate identity programs (CIP), presentations, banners, icons, and social media content. Routes tasks to specialized sub-skills or built-in modules.

## Capabilities

### Logo Design
- 55+ styles available
- 30 color palettes and 25 industry guides
- AI-assisted generation with style and palette selection

### Corporate Identity Program (CIP)
- 50+ mockups: business cards, letterheads, brand materials
- 20 styles available
- Consistent brand application across deliverables

### Presentations
- HTML slides with Chart.js integration
- Strategic copywriting formulas (PAS, AIDA, FAB)
- Data-driven layouts

### Banner Design
- 22 art direction styles
- Social platforms, ads, web, and print
- Precise platform-specific dimensions

### Social Media
- Multi-platform image design
- HTML/CSS to screenshot conversion
- Supports Instagram, Facebook, Twitter/X, LinkedIn, and more

### Icon Design
- SVG icons in 15 styles
- Text-based output for easy integration

## Sub-skills

This skill delegates to:
- **brand** — brand voice, visual identity, messaging frameworks
- **design-system** — design tokens, component specs, CSS variables
- **ui-styling** — shadcn/ui, Tailwind CSS, accessible components
- **banner-design** — platform-specific banner creation
- **slides** — strategic HTML presentations
- **ui-ux-pro-max** — UI/UX quality standards and patterns

## Requirements

- Python 3 (for logo/icon generation scripts)
- Gemini API key (for AI-assisted generation)
- Libraries: google-genai, pillow
