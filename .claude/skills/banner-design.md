# Banner Design

Comprehensive banner creation system for multi-platform content.

## Supported Platforms & Dimensions

- Facebook (cover, post, story)
- Twitter/X (header, post)
- LinkedIn (cover, post)
- YouTube (channel art, thumbnail)
- Instagram (post, story, reel cover)
- Google Display Network (standard ad sizes)
- Website heroes
- Print (with bleed and safe zones)

## Workflow

1. **Requirements** — Gather purpose, platform, content, brand guidelines, style preferences, quantity
2. **Art Direction** — Select from 22 styles, source design references
3. **Design Generation** — HTML/CSS with AI-powered visuals
4. **Export** — PNG at platform-specific dimensions via Chrome DevTools with automatic compression
5. **Iteration** — Refine based on feedback

## Design Standards

- Max 2 typefaces per banner
- Single CTA per banner
- Minimum 4.5:1 contrast ratio
- Critical content within central 70-80% of canvas (safe zone)
- Platform-specific dimension compliance

## Supported Styles (22)

Minimalist, gradient-based, neon, 3D, glassmorphism, editorial, bold typographic, photography-led, illustrated, flat, duotone, retro, futuristic, organic, geometric, cinematic, pastel, dark luxury, vibrant, monochromatic, collage, and data-driven.

## AI Image Generation

- Standard Gemini model for fast iterations
- Gemini Pro for high-quality hero visuals

## Out of Scope

This skill does NOT handle:
- Video editing or motion graphics
- Full website design
- Print production and pre-press
